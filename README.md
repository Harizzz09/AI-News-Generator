# 📰 AI News & Blog Generator

An interactive command-line Python application that leverages AI to generate engaging blog posts and news articles on the fly. Users can input any topic of interest and dynamically generate follow-up paragraphs to expand their articles in real time.

---

## ✨ Features
* **Dynamic Topic Generation:** Generate a custom AI response based on any user-provided topic.
* **Interactive Expandability:** Prompt-driven loop allowing users to continuously append new paragraphs and explore sub-topics.
* **Secure Key Management:** Uses `python-dotenv` to securely load API credentials from local environment files, keeping sensitive keys out of source control.
